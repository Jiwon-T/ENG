지원T 전체 수정 코드 — 2026-10-03

이 ZIP은 기존 앱 전체 코드와 현재까지 작성한 선생님방 변경 사항을 함께 포함합니다. GitHub push 및 운영 배포는 하지 않은 코드 스냅샷입니다.

포함된 주요 변경
- 공용 학습 세트 이용 및 작성자별 수정·삭제 권한
- 선생님별 담당 학생·과목 조회와 관리자 설정
- 개인 커리큘럼: 작성자 및 최고 관리자 접근
- 단일/다중 학생 수업 입력, 공통 진도·과제 적용, 개인 출결·점수·피드백
- 저장(초안)과 반영(Notion → 기존 Make → 앱) 구분
- 앱 과제를 수업 내용 맨 아래 과제: 구간에 작성하여 기존 과제 추출 연동 사용
- 학부모/학생 리포트 확인 및 재원생/이외 구분, 관리 화면 크기 축소
- 맨 위 월~일 주간 일정표, 모바일 7열 축소 화면과 일정 상세 창
- 주간 일정표 아래 정규 시간표, 보강·휴강·시험 일정 입력

검증 및 현재 제한
- 기존 검증을 포함하여 총 128개 테스트 통과. TypeScript 검사 및 Vite 빌드 통과.
- 실제 운영 Notion·Make 왕복 반영 및 로그인 상태에서의 새 화면 동작은 미검증입니다.
- 기존 Notion에서 앱으로 반영된 일정은 주간표에서 확인 가능하며, 기존 원본은 Notion 링크로 열람합니다. 앱에서 생성한 일정은 앱에서 수정 가능합니다.
- 영어 외 과목의 수업 일지 반영은 Make 과목 매핑을 준비한 뒤 teacherWorkspaceConfig/notion의 supportedSubjects 설정을 확대해야 합니다. 준비 전에는 반영을 차단합니다.
- 정규 반·시간표 저장은 현재 앱의 teacherClasses에 저장됩니다. 기존 Notion 정규 시간표의 자동 가져오기 및 앱→Notion 정규 반 저장은 아직 구현되지 않았습니다.
- 새 선생님은 최고 관리자가 담당 학생·과목을 연결해야 사용 가능하며, 일정 반영에는 Notion 선생님 페이지 ID 연결이 필요합니다.
- 모바일 화면의 실제 브라우저 시각 검증은 아직 하지 않았습니다.
- 웹 푸시 알림 기능은 보류 상태이므로 이 ZIP에는 포함하지 않았습니다.

개발 실행
1. 기존 프로젝트를 백업한 뒤 ENG-main 폴더의 파일을 사용합니다.
2. npm ci
3. 기존 환경변수를 유지하거나 .env.example을 참고해 설정합니다. 실제 비밀값은 ZIP에 포함하지 않았습니다.
4. npm run dev / npm run lint / npm test / npm run build

운영 적용 준비
- 서버 API 코드와 firestore.rules를 함께 적용해야 합니다. 규칙 파일을 포함했다고 운영 규칙이 자동으로 바뀌는 것은 아닙니다.
- 관리자 설정의 Notion 입력 연결 준비를 실행하면 기존 수업 일지 및 일정 DB에 앱 기록 ID 등 필요한 속성을 추가하도록 작성되어 있습니다. 이 작업은 아직 실행하지 않았습니다.
- 저장은 앱 초안만 저장합니다. 반영은 Notion 원본 생성·수정 후 기존 Make 버튼 연결을 호출합니다. 학부모에게 문자를 직접 발송하는 기능은 추가하지 않았습니다.
