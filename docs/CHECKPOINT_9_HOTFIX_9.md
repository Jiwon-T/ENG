# 입학·상담 원서 통합과 담당 선생님 선택

체크포인트 9 및 핫픽스 1~8 전체를 포함합니다. 이번 요청의 1번만 구현했습니다. 다음 구간은 학생 카드 클릭 → 상단 탭이 있는 관리 모달입니다.

## 원서 화면

첨부 입학원서.jpg와 image(20261005-160306).png를 확인했습니다. 기존 상담 details 토글을 제거하고 학생·보호자 정보 → 학습 수준·상담 내용 → 과목별 수강 → 수강료·납부 안내 → 동의·서명 확인 순서로 한 화면에 표시합니다. 국어·영어·수학·과학의 내신/모평 점수·등급과 진단평가는 원서처럼 표로 표시하며 작은 화면에서는 표를 가로로 스크롤합니다. 연락처·학교·학년은 기존 노션 속성을 사용하고, 생년월일·주소·알게 된 경로도 학생 정보 영역에서 입력합니다. 보호자 호칭 입력도 추가했습니다. 필요한 항목부터 초안을 저장할 수 있으며 수강 과목과 시작일 등 기존 필수 규칙은 유지합니다.

## 실제 노션 DB 변경

사용자님의 상담 속성 추가 요청에 따라 DB_학생 관리 데이터 소스 f5f0d0f1-c79a-82a4-bf6a-87062746d32d에 아래 36개 속성을 추가했습니다. 추가 전/후 조회를 비교해 기존 26개 속성의 설정이 그대로임을 확인했습니다. 기존 학생 값 수정, 테스트 학생 생성, 배포, Make 변경은 하지 않았습니다.

| 속성 | 종류 |
| --- | --- |
| 생년월일, 동의 확인일 | 날짜 |
| 수업 가능 요일 | 다중 선택: 월·화·수·목·금·토·일 |
| 개인정보 동의 | 선택: 미확인·동의·미동의 |
| 서명 원서 보관 | 체크박스 |
| 주소, 알게 된 경로, 이전 학습 기간, 이전 학원명, 사용 교재, 이전 학습 내용, 학습 목표, 수업 가능 시간, 상담 참고 사항, 서명자 이름, 보호자 호칭 | 텍스트 |
| 국어·영어·수학·과학별 ‘입학 내신 점수’, ‘입학 모평 점수’ | 숫자: 미입력 null과 0점 구분 |
| 국어·영어·수학·과학별 ‘입학 내신 등급’, ‘입학 모평 등급’, ‘입학 진단평가’ | 텍스트: 숫자·A/B 등급 및 진단 설명 보존 |

신입생 노션 반영 시 이 속성을 학생 CREATE 요청에 함께 넣습니다. 별도 추가 쓰기나 두 번째 학생 페이지 생성 없이 기존 불변 등록 ID와 응답 유실 복구를 유지합니다. 노션 학생 페이지 본문의 기존 상담 백업도 유지합니다. 상담 속성의 형식과 선택 옵션이 맞지 않으면 학생 생성 전 구체적인 오류로 중단합니다. 긴 메모는 Notion 글자 제한 안에서 나누고 이모지 등 Unicode도 보존합니다.

상담 원서는 비공개 등록 자료로 유지하고 학생·학부모 일지 리포트나 성적 그래프에 자동으로 내보내지 않습니다. 기존 버전에서 이미 반영한 학생의 상담 내용을 일괄 덮어쓰거나 본문에서 속성으로 역이관하지 않았습니다. 이번 속성 연결은 새로 반영하는 등록에 적용됩니다.

## 지원T 선택

노션의 영어 이지원T 페이지 3ec0d0f1-c79a-8108-b714-c1d6fc390ba2는 DB_선생님 소속, 재직, 담당 과목 영어입니다. 기존 코드에서 관리자 계정의 학원 접근 문서가 이미 존재하지만 notionTeacherPageId가 비어 있으면 기본 지원T 연결을 추가하지 않아 목록에서 빠지는 경로를 수정했습니다. main 관리자의 비어 있는 연결은 앱의 기존 기본 지원T 페이지로 해석하며 실제 접근 문서를 수정하지 않습니다. 목록 조회와 실제 등록 반영 검증이 같은 연결 해석을 사용합니다.

비활성·타학원·퇴직·과목 불일치와 중복 계정 연결은 계속 제외하거나 차단합니다. 임의의 일반 계정에 권한을 부여하지 않습니다. 원서에 담당·반 목록 새로고침을 추가하고 해당 과목의 재직 선생님이 없으면 원인 확인 안내를 표시합니다. 운영 Firebase 문서나 배포된 화면을 직접 확인하지 않았으므로 지원T 누락 원인은 코드상 재현한 경로이며 실제 서버에 이 코드가 적용돼야 목록이 바뀝니다.

## 검증

테스트 416개 통과. TypeScript 검사, Vite 빌드, 네이티브 서버 import 검사 통과. 기존 chunk 크기 및 firebase 혼합 import 빌드 경고는 남습니다.

통합 원서의 펼쳐진 항목·현재 수준 표·빈 담당 안내, 관리자 기본 지원T 노출과 실제 배정 검증, 비활성/타학원 차단, 상담 속성 전체 매핑·0점·미입력·긴 Unicode, 생성 응답 유실 시 한 번만 생성, 잘못된 상담 스키마의 사전 차단을 검증했습니다. 쓰기 테스트는 가짜 Notion/Firestore에서 수행했고 실제 노션에는 위 스키마 추가만 수행했습니다.
