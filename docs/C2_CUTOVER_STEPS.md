# 앱 전용 전환 — 사용자 순서 (2026-10-09 기준)

전체 자료 이전은 로컬 도구로 끝났습니다(앱 전용 전환·문자·Make 변경은 하지 않음). 아래는 배포 뒤에 관리자가 누를 순서입니다. 각 버튼은 자체적으로 최종 대조를 하고, 문제가 있으면 전환하지 않습니다.

## 학원 결정 (코드에 반영됨)
- **Notion과 앱 값이 다르면 앱 값이 맞습니다.** 일정 확인은 앱 값을 정답으로 봅니다. 미완료 반영이 있는 반·교재도 앱 값을 지킵니다.
- **앱에서 삭제한 자료는 의도된 것입니다.** 옮기지 않고 정상으로 건너뜁니다. 반·교재의 삭제 요청은 확정 때 삭제 완료로 정리됩니다.
- **일지는 2026-09-20 이후만 옮깁니다.**
- **테스트용 선생님 페이지는 옮기지 않습니다.** 화면에서 `옮기지 않음`으로 기록합니다.

## 이번에 고친 것
- 선생님·학생·수강 행 중 확인이 필요한 행을 `옮기지 않음`으로 기록할 수 있습니다.
  - 이력이 남고, 이후 동기화에서도 계속 빠지며, 학생·선생님 전환에서 제외됩니다.
  - 확인이 필요한 행에만 쓸 수 있습니다.
- 학생·선생님 전환은 반이 앱 전용이어야 실행됩니다(`CORE_CLASS_MIGRATION_REQUIRED`). 그래서 연결 정리 카드의 순서를 **반·교재 → 학생·선생님**으로 바꿨습니다. 각 단계의 위치 안내에는 누를 버튼 이름까지 적었습니다.

## 순서
0. **배포**: ENG-repo를 GitHub에 올리고, Vercel 배포가 끝나는 것을 확인합니다.
1. **반·교재·시간표**: 설정 탭 → `반·정규 시간표·교재 이전 열기` → `반·교재 앱 저장본 확정`
   - 최종 대조를 자동으로 다시 한 뒤 확정합니다.
2. **학생·선생님·수강**: 설정 탭 → `학생·선생님·수강 이전 열기`
   1. `전체 자료 이전 시작·재개`: 최신 상태로 한 번 더 가져옵니다. 전환은 마지막 가져오기가 15분 이내여야 하므로 바로 이어서 진행합니다.
   2. `선생님` → `저장본 조회` → 테스트 선생님 행 옆의 `옮기지 않음`
   3. `학생`, `선생님`, `수강` 각각 `비교 검증 완료 기록`
   4. `최종 대조 후 앱 전용 전환`
3. **일정**: 시간표·일정 탭 → `일정 앱 전환`(관리자)
4. **수업 일지**: 설정 탭 → `일지 앱 전환` → ③ `앱 전용 전환`
5. **문자 템플릿**: 설정 탭 → `문자 템플릿 영구 저장·동기화` → `문자 템플릿 앱 전환`
6. **성적**: 성적 관리 탭 → 맨 아래 `관리자 도구` → `성적 앱 전환`

각 단계가 끝나면 설정 탭의 `Notion·Make 연결 정리 준비` 카드에서 해당 영역이 `앱 전용`으로 바뀌고, 다음 차례가 표시됩니다. 모두 끝나면 같은 카드의 정리 단계(Make 시나리오 끄기 등)를 승인 후 진행합니다.

## 문제가 생기면
- 버튼이 멈추면 안내 문구(오류 코드 포함)를 그대로 알려 주세요. 각 전환에는 `전환 해제`가 있고, 앱 자료는 보존됩니다.
