- 누락한 노션 속성 이름을 정확히 안내한다. 메모는 계속 선택 속성으로 취급한다.
- 수업일지 입력 검증 실패는 점수 문항 수·시간·평가 등 실패한 필드 이름을 안내한다. 원문 입력·연락처·수업내용은 로그에 넣지 않는다.
- 리포트 반영 후 노션 저장만 실패한 경우 기존 정상 리포트를 유지한다. 응답에 failureCode와 구체적인 경고·오류 ID를 제공하며, 해당 오류를 구조화한 서버 로그에도 남긴다.
- 수업일지 검증 단계의 400 오류도 오류 코드·오류 ID·단계를 기록한다. 노션 400/401/403/404/429를 구분해 속성 형식/인증/접근 권한/주소/제한 문제를 안내한다.
- 화면에서 서버의 구체적인 메시지가 기존 포괄적인 INVALID_INPUT 안내에 가려지지 않도록 수정했다.
- 저장 결과 확인·재시도는 기존 불변 요청/중복 생성 차단을 유지한다. 실패했다고 새로운 일지를 만들도록 안내하지 않는다.
