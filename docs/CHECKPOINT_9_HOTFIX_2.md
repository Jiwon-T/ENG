# 체크포인트 9 긴급 수정 2 — 일지별 삭제 선택

일지 조회 각 행에 일지 삭제 버튼을 추가했습니다. 날짜·학생·수업 내용으로 대상을 구분한 뒤 확인창에서 선택한 한 건만 삭제합니다. 원래 작성자와 관리자가 가능하며 담당 학생·과목 권한을 서버에서 다시 검사합니다.

미완료 반영 상태 자체는 삭제를 차단하지 않습니다. 활성 반영 임대가 끝난 뒤 선택한 초안의 앱 기록 ID로 노션 저장 결과를 확인합니다. 이미 저장된 노션 일지는 휴지통으로 옮기고 해당 초안의 앱 리포트를 제거합니다. 초안은 재반영 방지용 보관 상태로 남습니다. 이름·날짜로 다른 일지를 자동 병합하거나 삭제하지 않습니다.

노션 생성 요청의 응답이 유실됐고 실제 페이지를 아직 찾지 못한 경우, 원격 일지가 뒤늦게 나타날 가능성이 있으므로 삭제를 완료했다고 표시하지 않습니다. 기존 반영 재시도는 계속 가능합니다. 휴지통 요청이 유실된 경우에는 확인한 페이지 ID를 먼저 저장해 같은 페이지의 실제 상태를 다시 확인합니다. 삭제 중인 초안은 수정·발행·직접 리포트 재생성을 차단합니다. 지연된 Make 전송도 삭제된 앱 일지를 다시 만들지 않습니다.

기존 체크포인트 9와 모듈 경로 긴급 수정 1을 모두 포함합니다. 실제 운영 데이터 삭제·배포·문자 발송·Make 변경은 수행하지 않았습니다. 배포 후 일지 조회에서 사용자가 대상 한 건을 골라 실행합니다.
