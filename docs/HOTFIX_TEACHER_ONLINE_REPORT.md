# 핫픽스 — 학생 관리의 온라인 학습 리포트

2026-10-08. 신규 등록 구간보다 우선 처리합니다.

## 원인과 수정

학생 본인의 LearningReport는 Firestore의 studySessions, wordProgress, assignments를 사용합니다. 기존 TeacherReportReview의 ‘학생’은 일정·공개 수업·성적만 조회해 온라인 활동이 누락됐습니다.

학생 관리 → 리포트 확인 → **학생**을 누르면 ‘온라인 학습’이 기본으로 열립니다. 일정·수업 기록·성적 확인은 같은 화면의 기존 탭으로 유지합니다. 학부모 공개 화면에 새 온라인 자료를 공개하지 않습니다.

표시: 단어장/문법/시험 대비 활동 이름, 날짜/시간, 학습 방식·범위·초 단위 시간, 정답 수/전체 수(0 포함), 해당 활동의 오답과 복습 확인 상태, 학습 단어 기록/암기 완료 수, 앱 과제 완료 상태입니다. 학생 앱 원본을 읽으며 앱 과제와 일지 과제는 혼동하지 않게 안내합니다.

## 접근과 읽기 전용

- 기존 signed teacher 인증과 studentKey/담당 과목 검사 뒤 조회합니다. Firebase UID를 브라우저 입력에서 받지 않습니다.
- 기존 student mapping의 firebaseUid와 users의 notionStudentKey backlink 및 student role을 대조합니다. legacy alias도 저장된 연결로만 확인합니다. 이름 추측 연결은 하지 않습니다.
- 계정 미연결/불일치/비활성은 별도 안내하며 다른 학생으로 fallback하지 않습니다. 조회 도중 연결이 바뀌어도 다시 대조해 원래 계정 기록을 반환하지 않습니다.
- 현재 앱의 단어·문법·영어 시험 대비 활동은 영어 담당 범위에서만 일반 선생님에게 표시합니다. 수학만 담당하면 활동 데이터 쿼리를 하지 않습니다. 관리자의 기존 접근 범위는 유지합니다.
- 과제 완료·오답 복습·포인트/XP·학생 데이터는 수정하지 않습니다. 학생 앱 원본 쓰기/저장 방식과 계정/권한 규칙은 변경하지 않았습니다.
- 계정 연결이 바뀐 경우 이전 온라인 자료가 잠시 표시되지 않도록 이 탭은 기존 화면 캐시를 재사용하지 않습니다. 오프라인 탭의 기존 캐시/분기는 유지합니다.

## 제한과 배포 확인

- 학습 세션은 uid + createdAt + 문서 ID 정렬로 20개씩 조회합니다. timestamp nanoseconds와 동일 시간의 문서 ID를 암호화 커서에 담아 중복/누락을 막고 학생/선생님/필터에 묶습니다.
- 단어 기록 수는 서버 aggregate count로 계산합니다. 앱 과제는 최근 10개입니다. 세션 오답은 최대 100개이며 초과 시 일부 표시 안내를 붙입니다.
- 기존 PARENT_SESSION_SECRET을 커서에 사용합니다. 새 비밀값은 추가하지 않았습니다. studySessions/wordProgress/assignments 인덱스 설정을 추가했으며 실제 클라우드 적용은 사용자에게 남깁니다.
- 원본 createdAt이 없는 매우 오래된 세션은 createdAt 정렬 쿼리에 포함되지 않을 수 있습니다. 현재 recordStudySession은 Timestamp를 항상 기록합니다. 이전 자료의 실제 필드 상태는 미확인입니다.
- 실제 김규림 계정의 mapping/학습 데이터, 클라우드 인덱스와 실제 화면은 확인하지 않았습니다. 원본이 미연결이면 임의로 연결하지 않고 안내합니다.
