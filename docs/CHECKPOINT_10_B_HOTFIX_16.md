# Hotfix 16 — 선택 일지 삭제

- 단일 작성 화면과 일지 수정 팝업이 공유하는 액션바에서 반영 버튼 오른쪽에 ‘일지 삭제’를 표시합니다.
- 저장된 본인 일지 또는 관리자 권한에만 표시합니다. 기존 archive-lesson API, revision 검사, 삭제 확인 문구와 Notion 휴지통 처리를 재사용합니다.
- 실패 시 입력을 유지합니다. 성공 시 해당 기록을 목록에서 제거하고 편집기를 초기화합니다. 다른 기록으로 이동했다면 그 기록의 입력을 초기화하지 않습니다.
- 새 입력에는 삭제 버튼을 표시하지 않습니다. 반영 진행 또는 결과 불확실 상태에 대한 기존 서버 보호 조건은 그대로입니다.

## 반 반영 실패 확인

사용자 스크린샷으로 DB_반 관리 ‘상태’가 Status이고 옵션이 대기 / 진행 중 / 중단임을 확인했습니다. 따라서 이 속성이 Select여서 실패한다는 가설은 제외합니다.
반 저장은 정규 시간표 및 교재 쓰기도 수행합니다. 정규 시간표 ‘상태’는 Status, ‘요일’은 Select로 전송합니다. 원격 오류 상세는 현재 gradeNotion에서 NOTION_400으로 축약되므로 실제 실패 속성과 단계는 확인하지 못했습니다. 운영 DB 수정과 재반영은 수행하지 않았습니다.
Notion→Firestore 최초 가져오기 및 백그라운드 동기화는 이번 변경에 포함하지 않았습니다. 화면의 기존 앱 반·계획 이동은 반대 방향입니다.

## 검증

타입 검사 통과. 전체 테스트 562개 통과. 브라우저에서 이번 버튼의 실제 배치 및 운영 일지 삭제는 확인하지 않았습니다. 기존 폼 레이아웃·저장/반영·권한·캐시·API는 변경하지 않았습니다.
