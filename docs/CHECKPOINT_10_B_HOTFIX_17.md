# Hotfix 17 — 반·시간표·교재 반영 실패 진단

- 기존 NOTION_400 등의 오류 문자열 계약을 유지하면서 Notion 응답의 안전한 진단 정보만 별도로 보존합니다.
- 원격 쓰기 단계, 거절된 속성명/전송 형식, Notion 요청 ID를 저장하고 관리자 설정의 재시도 목록에 표시합니다.
- 원본 오류 메시지, 학생 이름, 입력 값, 토큰은 저장하지 않습니다. 진단은 기존 요청의 실패 응답에서 가져오며 진단 수집을 위한 추가 Notion 요청이 없습니다.
- 재시도 실패에도 기존 목록 갱신을 실행합니다. 새 반영 시작 시 과거 진단을 지웁니다.
- Notion 연결로 세 DB 스키마를 읽었습니다. 상태/요일/진행도 형식과 옵션은 코드와 일치했습니다. 과거 운영 실패의 상세와 Firestore 연결 설정은 확인하지 못했고, 원인을 확정하거나 반영 성공을 검증한 것은 아닙니다.
- 운영 Notion 수정/재반영/Firestore 자료 이전은 수행하지 않았습니다. 적용 후 실패한 반 하나를 재시도하면 상세 진단을 확인할 수 있습니다.
- 브라우저 화면 검증은 이번 작업에서 수행하지 않았습니다. 수업 일지 디자인과 저장/삭제 흐름은 변경하지 않았습니다.

이전 절차는 [NOTION_FIRESTORE_IMPORT_PLAN.md](NOTION_FIRESTORE_IMPORT_PLAN.md)를 참고합니다.

검증: lint 통과, 전체 테스트 565개 통과, build 통과. 기존 CSS import 순서 및 번들 크기 경고는 남아 있습니다.
