# 자동 이전 도구 — 2026-10-09

문자 템플릿, 학생·선생님·수강, 교재·반·연결 시간표, 과거 성적에 `전체 자료 이전 시작·재개` 추가. 한 번 확인하면 기존 서버 API를 순차 호출하여 페이지 확인/가져오기/대조를 반복한다. 페이지 크기, 서버 잠금, 원본 ID, 권한, 충돌 판정, 저장 위치를 변경하지 않는다. 화면 진입만으로 호출하지 않는다.

- 문자 템플릿: 가져오기 전체 순회 → 원본 상태 점검. 충돌/원본 접근 불명은 중지하고 기존 편집 도구에서 확인. 동기화 워커 설치/실행 주기 변경이나 실제 문자 발송은 하지 않는다.
- 학생·선생님·수강: 세 종류 가져오기 → 각 종류 원본 점검 → 서버 연결 검증 승인. 문제 자료는 중지. 마지막 앱 전용 전환은 사용자가 확인한다.
- 교재·반·시간표: 교재 먼저 → 반·시간표 → 전체 최종 대조. 기존 final 순회 중단 위치도 재개. 활성화는 자동 실행하지 않는다.
- 성적: 매 페이지 최신 미리보기 토큰 확인 → 가져오기. 작성자 불명은 중지. 원본 재대조 새 순회는 기존 버튼으로 명시적으로 시작한다.

중지 버튼/컴포넌트 해제는 현재 요청 완료 후 다음 요청을 막는다. 이미 서버로 보낸 요청은 취소하지 않으며 서버에 진행 위치가 남는다. 탭 이동·새로고침·창 닫기 이후 자동 백그라운드 실행은 없다. 돌아와 시작·재개를 누른다. 교재 최종 대조 승인 유효시간(15분)은 기존 서버 기준 유지.

기존 단건/dry-run 도구는 템플릿·디렉터리·성적에서 상세 점검용으로 유지. 반복 이전에는 새 전체 버튼 사용. 운영 이전·전환·배포는 미실행. 실제 브라우저/스크린샷 확인은 미실행이며 UI 실제 검증 완료로 표시하지 않는다.

검증: lint, 전체 676개 테스트, build, 실제 Node 서버 import 통과. 기존 CSS import 위치/큰 번들 경고 유지. 자동 순회 순서, 충돌 중지, 중지 후 후속 요청 없음, 성적 토큰 갱신, 교재 우선, final 중단 재개, 반복 cursor 차단 테스트 추가.
