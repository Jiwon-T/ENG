# 체크포인트 10 B hotfix 10

- 수업·자습 자동 회차는 연·월(YYYY-MM)별로 독립 누적한다. 이전 달에만 유효한 기준 기록이 있으면 0 + 이번 증가량으로 시작한다. 같은 월은 기존 누적, 결석/없음 기준 제외, 정수 tenths와 half-up 규칙을 유지한다.
- 월 변경 안내를 회차 아래 표시한다. 이전 기록이 전혀 없으면 기존 빈칸 기본값을 유지한다. 직접 수정한 값과 저장된 기록은 재계산하지 않는다.
- 여러 학생 팝업에서 저장 후 X로 제거한 학생을 같은 날짜·과목·시작·종료로 다시 추가하면 저장 기록 ID·revision·내용·회차를 복원한다. 제거 기록은 컴포넌트 메모리에만 보관하고 계정 전환 시 비운다. 단일 학생 선택도 이미 메모리에 있는 정확히 일치하는 본인 기록을 재사용한다.
- 다른 선생님, 다른 시간, 삭제/취소 기록은 복원 대상으로 삼지 않는다. 이미 메모리에 없는 운영 기록 전체를 탐색하는 기능은 추가하지 않았다.
- 저장·반영 요청 계약, 권한 서버 검증, 브라우저 저장소 정책, 실제 운영 데이터는 변경하지 않았다. 이전 전체 변경을 포함한다.
- 검증: 타입 검사(lint), 전체 테스트 531개, 프로덕션 빌드. 실제 운영 화면에서 저장 → X 제거 → 같은 수업 학생 재추가 → ID·회차·내용 유지 확인은 사용자 배포 후 필요하다. 실제 Notion 저장이나 SMS/Make 실행은 하지 않았다.
