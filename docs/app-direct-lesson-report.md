# 앱 수업일지 직접 반영

앱의 반영은 저장된 초안을 서버에서 검증한 후 lessonReports에 직접 게시합니다. 학생 관계형 ID를 기존 내부 학생 ID로 연결하며, 계정·학부모 URL·PIN은 변경하지 않습니다. 학생과 학부모 DTO의 기존 공개 범위를 유지합니다.

리포트 게시 후 원본 노션 일지를 생성 또는 갱신합니다. 이 경로에서는 Make 웹훅이나 노션 전송 링크를 호출하지 않습니다. 노션에는 전송 완료를 완료로 표기합니다. 노션 개인 일지 복사 및 문자 본문 생성용 기존 Make 시나리오는 별도이며 이 변경으로 대체되지 않습니다.

노션 실패 시 리포트 게시 결과는 유지되고 report_published_notion_pending으로 표시합니다. 다시 반영하면 기존 초안 ID와 노션 페이지 ID를 재사용합니다. 최초 게시의 임시 리포트는 노션 페이지 ID가 확보되면 트랜잭션으로 이동하며 reportIdentity를 유지하여 과제 완료 식별자가 바뀌지 않습니다. 기존 compact 페이지 ID 기록도 통합합니다.

수업 내용·과제·평가·시간·소수 점수와 특이 사항을 직접 반영합니다. 지연된 Make 페이로드가 최신 앱 내용을 덮어쓰지 않도록 날짜 비교를 적용합니다.

배포: 기존 서버 환경 설정과 Firestore 규칙을 사용합니다. 운영 화면은 새로 조회하면 새 자료를 확인할 수 있습니다. 일정 반영·노션에서 직접 작성한 일지의 기존 자동화는 유지합니다. Make 구독 중단 여부는 별도 자동화까지 점검한 후 결정해야 합니다.

검증: TypeScript 검사, 215개 테스트, 프로덕션 빌드. 실제 운영 계정·노션 API 연결 확인은 별도입니다.
