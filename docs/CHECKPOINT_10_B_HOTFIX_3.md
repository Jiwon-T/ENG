# 체크포인트 10 B hotfix 3 — 입력 화면 0·4·5·6·7

## 구현
- 0: 여러 학생 이름 줄을 스크롤 상단에 유지하고, 개별/선택 N명 저장·반영 라벨을 구분했다. 하단 바 배경은 흰색 98%이다.
- 4: 허용된 학생 목록 안에서 이름·초성 검색한다. 단일 콤보박스는 오늘 그룹, 방향키/Enter/Esc, IME 조합 방어, 최대 280px 드롭다운을 지원한다.
- 5: 날짜·학생·과목·시작 시간이 같은 이미 불러온 기록으로 오늘 진행률을 계산한다. 사용자 확인에 따라 일치하는 기록이 없으면 미작성이다. 목록은 부분 로드될 수 있으므로 ‘현재 불러온 기록 기준’을 표시한다. 추가 서버 요청은 없다.
- 6: 수업·자습이 같은 시간 프리셋을 사용한다. 오늘 정규 시간과 +60/+80/+90/+120분을 제공하고 직접 입력도 유지한다. +80은 추천 표시이며 자동 변경하지 않는다. 자정 초과 계산은 거절한다.
- 7: 개발용 요청 측정만 추가했다. 메모리에 작업 종류·시간·성공 여부만 최대 200건 보관하며 계정 변경 시 비운다. 프로덕션 JS에서는 제거된다. 기존 저장 응답 재사용이 이미 구현돼 있어 추가 최적화나 prefetch는 적용하지 않았다.

## 요청 측정
실제 request/load/submit 함수 코드를 추출한 모의 실행이다. fetch에 30ms 지연을 주었다. 실제 운영 지연이나 콜드 스타트 측정이 아니다. 요청은 인증 래퍼 호출 수이며 실패 시 인증 재시도 HTTP 횟수와 다를 수 있다.

| 시나리오 | 전 요청/시간 | 후 요청/시간 |
|---|---:|---:|
| 첫 로드 | 4 / 109ms | 4 / 73.9ms |
| 미캐시 커리큘럼 탭 | 2 / 36.9ms | 2 / 37.9ms |
| 일지 저장 | 1 / 35.4ms | 1 / 32.9ms |
| 동일 내용 반영 | 1 / 34.4ms | 1 / 35ms |
| 학생 선택 | 1 / 33.5ms | 1 / 40ms |

횟수는 동일하다. 시간 차이는 모의 실행 변동이며 성능 개선으로 해석하지 않는다. 저장 응답 계약이나 캐시 정책 변경 없이 측정 도구만 전달한다.
