# 남은 Notion 의존 점검과 수정 — 2026-10-09

기준: `c2-lesson-app-paths`. 서버 코드에서 Notion을 부르는 곳을 모두 찾아, 각 경로가 앱 전환 뒤 Notion 없이 동작하는지 확인했습니다. 운영 실행·배포는 하지 않았습니다.

## 결과 요약
| 영역 | 전환 후 상태 | 비고 |
|---|---|---|
| 학부모 리포트·PIN 로그인 | Notion 사용 안 함 | PIN은 저장된 값으로 검증합니다. 리포트는 `lessonReports`·`academicRecords`를 읽습니다. |
| 학생 리포트·과제 완료 | Notion 사용 안 함 | **결함 수정 1** |
| 리포트 주소·계정 연결(`report-slug`, `student-link`) | 학생·선생님 전환 시 앱 사용 | `lookupStudentIdentity`가 이미 전환 여부를 따릅니다. |
| 관리자 학생 목록(계정 연결 화면) | **수정 3** 이후 앱 사용 | 전에는 항상 Notion만 읽어 앱 등록 학생이 빠졌습니다. |
| 문자(학생 정보·템플릿·발송) | **수정 2** 이후 Notion 없이 동작 | 템플릿은 기존 `MESSAGE_TEMPLATE_READ_MODE=firestore` 설정으로 바꿉니다. |
| 상담·신규 등록 | 학생·선생님 전환 시 앱 사용 | C1 앱 등록 경로(`commitAppStudentRegistration`)입니다. |
| 선생님 담당 권한(grant·담당 범위) | 학생·선생님 전환 시 앱 사용 | `saveCoreGrant`·`readCoreScopes`입니다. |
| 일정 | 일정 전환 시 앱 사용 | `appSchedulesActive`입니다. |
| 반·교재·시간표 | 반 전환 시 앱 사용 | `classesActive`입니다. |
| 성적 | 이미 앱 전용 | 저장·반영·삭제·조회 모두 앱입니다. 옛 Notion 저장 충돌을 해결하는 기능만 Notion을 씁니다. |
| 일지 | 일지 전환 시 앱 사용 | 이전 구간에서 연결했습니다. |
| 무결성 점검(관리자 진단) | Notion 읽음 | 관리자가 직접 누를 때만 실행합니다. 원본 대조용이라 유지합니다. |
| Make 웹훅(일지·성적·일정 반영) | 전환된 자료는 반영 거부 | 시나리오 중단은 사용자 승인 후 진행합니다. |

## 이번에 고친 결함
1. **학생 과제 완료 체크(`assignment-completion`)**
   - 문제: 화면에 내려가는 리포트 번호는 `reportIdentity || notionPageId` 기준인데, 완료 저장은 `notionPageId`만 썼습니다.
     - 앱에서 새로 만든 일지(`notionPageId: null`)가 하나라도 있으면 그 학생의 완료 체크가 전부 500 오류가 됩니다. 일지 전환 직후부터 생기는 문제였습니다.
     - 앱에서 먼저 반영한 일지는 번호가 맞지 않아 지금도 "과제 없음"이었습니다.
   - 조치: 화면과 같은 `lessonReportId`를 쓰도록 바꿨습니다(`findAssignmentTarget`). 기존 Notion 리포트에 저장된 완료 기록은 번호가 같아서 그대로 유지됩니다.
2. **문자 준비(`prepareTeacherMessage`)**
   - 문제: 학생·선생님 전환 뒤에도 완성된 문자 본문을 항상 Notion 학생 페이지에 백업 기록했습니다. 또 앱에서 등록한 학생은 "Notion 학생 DB 페이지" 검사에 걸려, 문자 준비와 발송이 모두 막혔습니다.
   - 조치: 전환 뒤에는 앱 기록을 기준으로 삼습니다. 앱 등록 학생은 ID만 확인하고, Notion 백업은 하지 않습니다(본문은 이미 Firestore에 저장됨). 전환 전 동작과 기존 테스트(백업·재시도)는 그대로입니다.
3. **관리자 학생 목록(`/api/teacher/notion-students`)**
   - 조치: 학생·선생님 전환 뒤에는 앱 학생 명부(`readDirectoryStudents`)를 읽습니다. 응답 형식은 같습니다.

## 검증
- lint 통과, 테스트 703/703, build 통과, Node 서버 import 통과.
- 새 테스트:
  - 과제 완료 번호가 학생 화면과 일치(Notion·앱 전용·앱 먼저 반영 리포트), 기존 번호 호환
  - 전환 뒤 앱 등록 학생에게 Notion 학생 페이지 조회·백업 없이 문자 준비
  - 전환 전후 학생 목록 출처 전환(전환 뒤 Notion 호출 0)
- 실제 화면·운영 데이터로는 확인하지 않았습니다.

## 남은 일 (권장 순서)
1. 문자 템플릿 읽기 전환을 환경변수 대신 검증 기반 스위치로 바꾸기(일정·일지와 같은 방식).
2. 관리자·원장 일지 조회와 문자 화면의 일지 목록을 날짜·학생별 서버 조회로 바꿔 읽기 비용 줄이기. 지금은 학원 전체 일지를 읽은 뒤 서버에서 거릅니다.
3. 이력 기반 일지 복원 API.
4. 모든 자료 종류의 전환을 마친 뒤 Make 시나리오 중단(사용자 승인)과 Notion 토큰 권한 축소 검토.
