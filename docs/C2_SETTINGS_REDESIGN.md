# 관리자 설정 탭 재구성 (앱 전용 이후) — 2026-10-09

모든 영역이 앱 전용으로 전환된 뒤(`coreMode`) 관리자 설정 탭은 평소 관리 화면만 보여 줍니다. 전환 전이거나 다른 학원이면 기존 화면을 그대로 씁니다.

## 화면
1. **선생님 관리** (`TeacherManager.tsx`)
   - 위쪽 요약: 사용 중인 선생님 · 담당 미설정 · 담당이 있는 학생 · **담당 선생님 없는 학생**(누르면 이름 목록)
   - 선생님 카드: 이름, 직책(원장/선생님), 과목별 담당 학생 수, 학생 이름 미리보기, 상태(사용 중 / 담당 미설정 / 사용 중지)
   - 카드를 누르면 편집 창이 열립니다.
     - ① 기본 정보: 화면에 보일 이름, 직책(관리자만 변경)
     - ② 담당 학생: 과목 칩, 이름·초성 검색, 전체/담당 중/미배정 보기, 학생별 체크. "보이는 학생 모두 담당"과 "담당 해제"로 한꺼번에 바꿀 수 있고, 다른 선생님이 같은 과목을 담당 중이면 표시합니다.
     - 아래 버튼: 저장, 사용 중지/다시 사용(관리자만, 본인·관리자 계정은 불가)
2. **문자 템플릿** (`AppTemplateManager.tsx`): 템플릿을 골라 고치고 앱에 저장합니다. Notion 동기화 버튼은 없습니다.
3. **삭제한 일지 복원**: 그대로입니다.
4. **정리·점검 · 관리자용**(접힘): Notion·Make 연결 정리 준비, 연결 정합성 점검, 기존 계정·리포트 관리.

화면에서 뺀 것: 학원 공용 DB 연결, 문자 템플릿 동기화·전환, 학생·선생님·수강 이전, 반·교재 이전, 일지 앱 전환, Notion 반영 상태와 Notion 선생님 페이지 ID 입력, "현재 노션 담당 불러오기", "Notion 입력 연결 준비"

## 서버
- **새 선생님 등록 가능**:
  - 전환 뒤에는 앱 기록이 있는 선생님만 담당을 저장할 수 있었습니다. 그래서 관리자 외에 앱 기록이 없던 선생님(예: 영신찬)에게는 담당을 줄 수 없었습니다.
  - 이제 관리자가 선생님·원장 역할 계정에 처음 저장하면 앱 기록을 만듭니다. 원장은 새로 만들 수 없습니다.
- **Notion 선생님 페이지 없이도 담당 저장**: 앱 기록이 담당의 기준입니다. Notion 페이지가 연결된 선생님은 기존처럼 수강 기록의 담당 표시도 함께 맞춥니다.
- **`teacher-access`**:
  - 관리자가 선생님방 사용을 중지하거나 다시 허용합니다. 중지해도 담당과 작성 자료는 보관되고, 중지된 선생님은 선생님방을 쓸 수 없습니다(`TEACHER_NOT_CONFIGURED`).
  - 관리자 본인과 관리자 계정은 중지할 수 없습니다.
