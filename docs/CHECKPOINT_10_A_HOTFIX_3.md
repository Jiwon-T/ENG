# 체크포인트 10 A hotfix 3 — 공용 DB 조회 오류·로딩 개선

2026-10-06. A hotfix 2까지의 전체 변경을 포함합니다. B는 진행하지 않았습니다.

## 확인된 원인

두 운영 오류 ID(090e26b8-3227-40e6-a2c0-c9999d5d3f26, 83c92106-a0a7-4ed1-a080-2d94860e4e93)는 모두 GET /api/teacher/workspace에서 NOTION_400, workspace-data 단계의 502로 기록돼 있습니다. 연결된 운영 DB 스키마를 읽은 결과 기본 영어 수업일지 DB와 일정 DB 모두 학원 속성이 없습니다. 공용 DB 연결 뒤 workspaceSourceFilter가 존재하지 않는 학원 속성에 rich_text 조회 조건을 보내는 것이 오류 원인입니다. 기존 오류 문구가 저장 선택값 문제로 안내해 혼란을 주고 있었습니다.

## 수정

- Notion 조회 전에 실제 DB 스키마와 조회 조건을 대조합니다. 없는 속성의 값 비교는 불일치, 없는 속성의 비어 있음 조건은 일치로 해석하고 AND/OR를 보존해 유효한 조회 조건으로 만듭니다. 불일치로 확정된 조건은 원본을 조회하지 않습니다. select/status 및 rich_text/title 형식도 실제 속성 형식에 맞춥니다. 잘못된 다른 형식은 명확히 오류로 중단합니다.
- 기본 영어 일지는 기존 main 학원의 영어 원본 범위에서만 학원 속성 없는 이력을 읽습니다. 기존 지원T 작성자 해석, 현재 담당 학생·과목·학원 확인과 소유권 규칙을 유지합니다.
- 기존 일정도 main의 공용 일정 원본에서 학원 속성 없는 자료를 읽고, 실제 담당 선생님 관계와 과목·대상 학생 범위를 재검증합니다. 공동 담당을 단독 작성자로 바꾸지 않습니다. 담당 관계가 없는 일정의 작성자를 임의로 추측하지 않습니다.
- 실제 스키마 확인 없이 Notion 속성을 새로 만들거나 원본 데이터를 일괄 수정하지 않습니다. 기존 페이지/학생/리포트 ID를 유지합니다. 조회 오류는 조회 조건/연결 DB 문제라는 안내로 구분합니다.
- 일지 엑셀 안내 문구는 독립 CSS 클래스로 11px, 줄간격 1.6으로 줄였습니다.

## 로딩 개선

1. 페이지별 빠른 앱 조회와 최신 조회를 동시에 시작합니다. 빠른 요청이 끝날 때까지 최신 요청을 기다리던 직렬 대기를 제거했습니다. 늦은 빠른 응답은 최신 화면을 덮어쓰지 않습니다. 계정/필터 변경 시 이전 응답이 적용되지 않는 기존 보호를 유지합니다.
2. 일지 조회의 로컬 기록과 Notion 원본도 서버에서 병렬로 읽습니다.
3. 같은 사용자 토큰의 동시 인증 요청은 진행 중인 검사 한 번을 공유합니다. 완료된 계정 상태는 캐시하지 않아 이후 요청의 정지·취소 검증은 다시 실행됩니다. 앱 권한/소속/담당 검증은 요청마다 유지합니다.
4. 일지는 원래 결과에서 제외하던 학생 관계 없는 과거 행을 Notion 조회 조건에서부터 제외합니다. 앞선 A의 운영 조회 기준 874행 중 781행을 불필요하게 내려받지 않게 됩니다. 이력은 삭제/변경하지 않습니다. 표시할 수 있던 관계 있는 원본은 같은 기준으로 유지합니다.
5. DB 스키마 읽기도 기존 사용자·권한 범위 캐시로 중복을 줄이고 새로고침/변경 무효화 흐름을 유지합니다. 브라우저 저장소에 학생 데이터나 토큰을 보관하지 않습니다.

## 검증

전체 회귀 테스트 461개, 타입 검사, native Node 서버 import, 프로덕션 빌드 통과. 큰 번들/Firebase mixed import 경고는 기존대로 남아 있습니다.

추가 5개 테스트는 없는 학원 속성의 조건 해석, status/title 및 mirror 필터 호환, 실제 운영 수업일지/일정 스키마를 재현한 전체 원본 조회와 ID 보존/권한 제거, 공동 담당·타 학원 접근 차단, 동시 인증 중복 제거 및 다음 요청 재검증을 확인합니다. 기존 병렬 빠른/최신 응답 역전 방지 테스트도 통과합니다.

운영에서는 오류 로그와 두 DB 스키마만 읽었습니다. 운영 데이터/스키마 수정, 배포, 발송, Make 변경은 하지 않았습니다. 실제 사용자 화면 로딩 시간과 재배포 후 두 오류의 해소는 아직 운영 화면에서 확인하지 않았습니다. 몇 초 또는 몇 퍼센트 빨라졌다는 운영 측정 수치는 제공하지 않습니다.
