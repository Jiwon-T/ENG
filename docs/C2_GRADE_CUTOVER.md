# 성적 앱 전용 전환 스위치 — 2026-10-09

기준: `c2-app-only-notion-gaps`. 운영 실행·배포는 하지 않았습니다.

## 왜 필요했나
성적은 이미 앱에서 작성·수정·삭제했지만, Make 성적 웹훅(`syncAcademicPage`)은 **앱이 직접 쓴 성적만** 보호했습니다.
- Notion에서 온 성적을 Notion에서 고치면 앱 값을 덮어썼습니다.
- 학생·선생님 앱 전환 뒤에도 Notion 수강 정보 변경이 리포트의 과목 정보를 바꿀 수 있었습니다.
그래서 Make 성적 시나리오를 안전하게 끌 기준이 없었습니다.

## 바뀐 것
- `api/_lib/academicAuthority.ts`: 검증 기반 성적 스위치입니다. 일지·템플릿과 같은 구조입니다.
  - 전환 조건(한 트랜잭션에서 다시 확인): 학생·선생님 앱 전환, 과거 성적 이전 전체 순회 완료(오류 없음), 그 순회가 15분 안에 끝남, 반영 중이거나 결과가 미확정인 성적 없음, 진행 중인 순회 없음.
  - 검증 기록(`academicVerificationRuns`)과 함께 켜고, 이력을 남깁니다. 손으로 만든 표식은 무시합니다. 해제해도 앱 성적은 그대로입니다.
- 전환 뒤 보호:
  - Make 성적 수신은 반영하지 않습니다(`APP_AUTHORITY`). 기존 앱 반영(Notion 사본) 경로는 영향이 없습니다.
  - 과거 성적 이전 도구(미리보기·가져오기·새 순회)와 성적 충돌 도구를 닫습니다(`ACADEMIC_APP_ACTIVE`).
- **수강 정보 보호**: 학생·선생님 앱 전환 뒤에는 Notion 수강 페이지 수신을 반영하지 않습니다. 성적 스위치와 별개로, 전환 즉시 적용됩니다.
- 화면: 과거 성적 이전 패널 맨 위에 `성적 앱 전환` 카드를 추가했습니다. 점검표 5개와 버튼 하나(`대조 후 성적 앱 전용으로 전환`)입니다.
  - 최근 대조가 15분 안이 아니면, 새 순회 → 자동 대조 → 전환을 차례로 실행합니다.
  - 학생·선생님 미전환이나 반영 중 성적처럼 사람이 정리해야 하는 항목이 있으면 버튼이 꺼집니다.
  - 전환 뒤에는 Notion 이전 도구를 숨깁니다.
- `Notion·Make 연결 정리 준비` 카드: 성적 영역과 "Make 성적 시나리오 끄기"가 이 스위치를 기준으로 판정합니다.
