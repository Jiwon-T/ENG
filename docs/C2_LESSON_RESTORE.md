# 삭제한 일지 복원 — 2026-10-09

기준: `c2-lesson-read-scope`. 운영 실행·배포는 하지 않았습니다.

## 사용
설정 탭(관리자·원장)의 **삭제한 일지 복원** 카드를 펼치면 목록을 불러옵니다. 펼치기 전에는 아무것도 읽지 않습니다.
- 목록: 날짜·학생·과목·시작 시각·작성 선생님·삭제 시각, 그리고 복원 방식 표시
  - **리포트까지 복원**: 학생·학부모 리포트가 같은 문서 ID·reportIdentity로 다시 보입니다. 학생 화면의 리포트 번호와 과제 완료 기록도 그대로 이어집니다.
  - **초안으로 복원**: 전환 전에 삭제해 공개 리포트 사본이 이력에 없는 일지입니다. 비공개 초안으로 돌아오며, 리포트에 보이려면 다시 반영해야 합니다.
- `복원`을 누르면 확인창이 뜨고, 결과를 안내합니다.
- 일지 앱 전용 전환 전에는 "전환 후 사용 가능"으로 안내합니다. 전환 전 삭제는 Notion 휴지통 복원이 필요하기 때문입니다.

## 서버 (`api/_lib/appLessonRestore.ts`)
- `restoreAppLesson`: 한 트랜잭션 안에서 처리합니다.
  - 권한: 관리자, 같은 학원 원장, 또는 지금도 그 학생을 담당하는 작성 선생님
  - 현재 revision 확인, 학생의 학원 소속과 내부 연결 다시 확인
  - 삭제 이력(`lessonAppHistory/{id}:{revision}:archive`)에서 삭제 전 초안과 공개 리포트를 꺼냅니다.
  - 공개 리포트 ID에 그사이 다른 문서가 생겼거나, 같은 일지의 다른 공개 문서가 있으면 덮어쓰지 않고 중단합니다(`SOURCE_IDENTITY_LOCKED`).
  - 복원은 **새 revision**으로 기록하고, 공개 문서의 `teacherAppRevision`도 맞춥니다. 그래서 복원한 뒤 다시 고치고 반영해도 같은 ID로 정상 처리됩니다.
  - 복원 이력: `lessonAppHistory/{id}:{새 revision}:restore`
  - 이미 복원된 일지에 다시 요청하면 추가 쓰기 없이 성공으로 답합니다.
- `listArchivedAppLessons`: 권한 범위의 삭제 일지를 같음 조건만으로 최대 500건 읽고, 최근 삭제 순으로 100건을 보여 줍니다. 500건을 넘으면 일부만 표시한다고 안내합니다.
- 동작: `GET archived-lessons`, `POST restore-lesson`(`confirmed: true` 필요, 일지 앱 전용 모드에서만).
