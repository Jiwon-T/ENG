# C2 일지 앱 전용 전환 스위치 — 2026-10-09

기준: `c2-lesson-migration` 태그(ENG-repo). 운영 실행·전환·배포는 하지 않았습니다.

## 사용자 조작
설정 탭의 `일지 앱 전환` 카드에서 3단계로 진행합니다. 단계마다 큰 버튼은 하나입니다.
1. **과거 일지 가져오기**: `과거 일지 가져오기 시작` 1회. `저장 없이 미리 점검`도 고를 수 있습니다.
2. **확인 필요 항목**: 유형별로 묶어 보여 줍니다. 확정할 수 있는 유형은 `모두 …` 한 번으로 처리됩니다. 확정하면 다시 확인이 자동으로 시작되고, 진행 중이던 확인이 놓친 결정도 한 번 더 자동으로 확인합니다. 확정할 수 없는 유형(학생 연결 없음, 중복 등)은 해결 방법을 함께 안내합니다.
3. **앱 전용 전환**: 점검표 5개(학생·선생님 전환 / 전체 대조 / 확인 필요 없음 / 반영 중 일지 없음 / 앱 경로 준비)를 자동으로 판정합니다. `최종 대조 후 앱 전용으로 전환` 1회로 끝납니다.
   - 최근 15분 안에 끝난 대조 결과가 "준비 완료"면 그 결과로 바로 전환합니다.
   - 아니면 서버가 최종 대조를 자동으로 실행하고, 끝까지 문제가 없을 때만 스스로 전환합니다. 문제가 나오면 전환하지 않고 2단계로 돌아갑니다.
   - 사용자가 직접 할 일: 누르기 전에 선생님들께 Notion 일지 직접 수정을 멈춰 달라고 알리는 것뿐입니다.

카드가 화면에 있는 동안은 작업이 자동으로 이어집니다. 창을 닫아도 진행 위치는 서버에 남습니다.

## 서버 (`api/_lib/lessonAuthority.ts`)
- `lessonAppActive`: 전환 표식(`lessonAppAuthority/main`)과 같은 해시의 검증 기록(`lessonVerificationRuns`)이 함께 있을 때만 true입니다. 손으로 만든 표식은 무시합니다.
- `activateLessonApp`: 한 트랜잭션 안에서 아래를 다시 확인한 뒤 표식·검증 기록·이력(`lessonAuthorityHistory`)을 씁니다.
  - 15분 안에 끝난 전체 실행이고, 원본 순회를 끝까지 마쳤고, 준비 완료와 증거 해시가 있음
  - 학생·선생님 전환 완료
  - 열린 보류 0건
  - 지금 반영 중인 일지 0건
- `requestLessonCutover`: 전환 버튼 하나의 동작입니다. 바로 전환하거나, `final` 실행을 `activateOnReady`로 시작합니다.
- `deactivateLessonApp`: 표식만 끕니다. 앱 일지·이전 저장본·공개 리포트는 그대로 두고 이력을 남깁니다.
- **잠금**: `LESSON_APP_PATHS_READY = false`. 일지 조회·저장 경로가 아직 앱에 연결되지 않아서, 이번 버전에서는 서버가 전환을 거부합니다(`LESSON_APP_PATHS_NOT_READY`). 점검과 최종 대조는 지금도 쓸 수 있습니다.

## 이전 작업 변경 (`lessonMigration.ts`)
- **`final` 모드**: 전체 실행과 같습니다. 끝나서 준비 완료면 미리 받은 확인으로 전환까지 이어갑니다.
- **빠른 건너뛰기**: 아래가 모두 그대로인 행은 다시 분류하지 않습니다(행당 읽기 약 2회). 소유 정보가 바뀌면 행 버전도 바뀌어 다시 저장됩니다.
  - Notion 수정 시각이 같음
  - 마지막으로 읽은 시점이 그 수정보다 2분 이상 뒤임(수정 시각이 분 단위로 반올림되기 때문)
  - 작성자·연결 구성 해시가 같음
  - 학생 내부 연결이 같음
- **결과 미확정 Notion 생성의 자동 판정**: 이번 실행은 원본을 끝까지 읽으면서 앱 기록 번호를 모았습니다. 그 번호가 원본에 있으면 "생성됨", 없으면 "생성 안 됨"으로 판정해 `lessonWriteEvidence/{일지 ID}`에 남깁니다. 지금 진행 중인 요청(잠금 중이거나 3분 이내)만 보류합니다. 다음 구간에서 이 증거로 일지의 미확정 상태를 정리할 수 있습니다.
- **전환 후 보호**:
  - 일지 이전을 다시 시작하지 못하게 막습니다(`LESSON_APP_ACTIVE`).
  - Make 웹훅의 일지 공개 리포트 반영도 막습니다(`APP_AUTHORITY`). 오래된 Notion 자료가 앱의 최신 값을 덮어쓰지 않게 하기 위해서입니다.
- **확정 일괄 처리**: 한 유형을 한 번에 확정합니다(`acknowledgeLessonMigrationHoldGroup`). 목록을 보여 준 뒤 바뀐 항목은 건너뜁니다.
- **상태 응답**: 유형별 건수를 실시간으로 계산하고, 확정 후 다시 확인을 기다리는 건수도 함께 돌려줍니다.
