# Hotfix 18 — 작성자 관계형 속성 생성 수정

사용자가 전달한 중2반·평여중1반 실패는 ‘반 DB 준비 / 작성자 선생님 (relation)’입니다. 기존 코드가 속성을 생성할 때 relation.database_id만 전송하고 단방향 관계 설정을 누락했습니다.

현재 앱의 Notion-Version 2022-06-28과 대상 DB ID를 유지하면서 relation에 type: single_property 및 single_property: {}를 명시합니다. 반과 교재 DB가 공유하는 준비 경로에 적용됩니다. 기존 담당 선생님/학생 관계, 상태, 반 저장 데이터 및 재시도 흐름은 변경하지 않습니다. 이미 존재하는 속성은 준비 함수가 그대로 보존합니다.

공용 DB 준비 경로의 실제 요청을 가짜 Notion 응답으로 검증합니다. 앱 기록 ID와 담당 선생님이 이미 존재하는 경우 작성자 속성만 생성하며, 기존 관계형 속성을 덮어쓰지 않는지 확인합니다.

운영 서버 배포·실제 반 2건의 재반영은 수행하지 않았습니다. 새 ZIP 적용 후 기존 ‘노션 반영 다시 시도’를 사용합니다. 이번 변경은 첫 번째 준비 단계의 잘못된 요청을 수정한 것이며, 이후 단계까지 운영 반영 성공을 확인한 것은 아닙니다.

참고: https://developers.notion.com/reference/property-object#relation

검증: lint, 테스트 566개, build 통과. 기존 빌드 경고는 그대로입니다.
