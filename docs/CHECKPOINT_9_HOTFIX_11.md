# 체크포인트 9 핫픽스 11: 시험기간 단어장 디자인

2026-10-06 한국 시간. hotfix-10 전체 누적 코드에 적용했습니다. 본 체크포인트 10 A 검증은 사용자 정정에 따라 보류했습니다.

## 변경
- 시험기간 카드: 흰 배경, 둥근 테두리, 은은한 그림자, 핑크 hover와 키보드 focus. 카드 본문 전체를 native button으로 열며 Enter/Space도 지원합니다.
- 관리자의 기간 관리/복사 버튼은 카드 본문 버튼 밖에 유지합니다. 중첩 버튼과 클릭 전파로 인한 잘못된 자료 열기를 피합니다.
- 개별 단어장: 흰 배경과 핑크 포인트, 일반 단어장과 같은 BookOpen 아이콘, 카드 전체 클릭을 유지합니다.
- 학교/학년/기간 필터: 흰 패널, 작은 상단 라벨, 정돈한 select, 핑크 focus. 모바일에서는 학교/학년 두 칸과 기간 전체 폭으로 배치합니다.
- 지난 시험기간: 현재 카드 아래 32px 간격을 둔 독립 흰색 카드. 보관 아이콘과 펼침 화살표를 사용하고 기존 펼치기/접기 및 과거 기간 선택 시 열림을 유지합니다.
- Windows에서도 기존 서버 import 검사가 실행되도록 파일 경로를 file URL로 변환합니다. 앱의 서버 기능은 변경하지 않습니다.

## 검증
전체 기존 테스트 421개 통과, TypeScript 검사와 native Node 서버 import 통과. 프로덕션 빌드 통과. 기존 큰 chunk 및 Firebase 혼합 import 경고는 유지됩니다. 새 디자인 전용 테스트는 추가하지 않았습니다. 실제 운영 화면 클릭 및 시각 검증은 수행하지 않았습니다.

## 배포 후 확인
1. 단어 세트 → 시험기간 대비 단어장에서 카드 흰 배경과 hover 핑크를 확인합니다.
2. 제목/날짜/빈 공간을 클릭해 해당 기간 자료가 열리는지, Tab과 Enter/Space로도 열리는지 확인합니다.
3. 개별 자료 카드가 흰색이며 클릭하면 기존 학습 화면이 열리는지 확인합니다.
4. 학교·학년·기간 필터, 목록으로 돌아가기, 지난 시험기간 펼치기/접기를 확인합니다.
5. 선생님 관리 화면의 기간·자료 관리와 새 기간으로 복사가 자료 열기와 독립적으로 동작하는지 확인합니다.
6. 모바일 폭에서 필터와 카드가 잘리거나 가로로 넘치지 않는지 확인합니다.
