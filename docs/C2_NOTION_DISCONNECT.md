# Notion·Make 연결 정리 준비 — 2026-10-09

기준: `c2-design-rosy-peach`. 이번 구간은 **확인 도구와 절차**만 만들었습니다. Make 시나리오 중단, 템플릿 반영 작업기 중지, Notion 권한 변경은 사용자가 승인 후 직접 진행합니다. 운영 배포·실행은 하지 않았습니다.

## 만든 것
1. **사용량 기록**(`api/_lib/notionUsage.ts`): Notion API 호출과 Make 웹훅 수신을 한국 날짜별로 `notionUsage/{YYYY-MM-DD}`에 셉니다.
   - Notion 호출: 요청 경로(예: `workspace:previous-lesson`, `cron:lesson-migration`, `webhook:academic`) × Notion DB 영역(일지·성적·일정·반·학생·템플릿·개별 페이지).
   - Make 수신: 종류(일지·일정·성적) × 결과(반영 / 전환 후 차단 `APP_AUTHORITY` / 오류 등).
   - Notion을 부르는 6곳(`academic.ts`, `notion.ts` 2곳, `teacherAcademicNotion.ts`, `teacherNotionPublish.ts`, `teacherStudentRegistrationNotion.ts`)에 한 줄씩 추가했습니다.
   - 페이지 ID·이름·내용은 저장하지 않습니다.
   - 기록은 응답을 기다리지 않으며, 실패해도 요청에 영향이 없습니다. Firebase 설정이 없는 테스트·로컬에서는 기록하지 않습니다.
2. **설정 탭 `Notion·Make 연결 정리 준비` 카드**(관리자, 펼칠 때만 읽음). 다음을 보여 줍니다.
   - 영역별 앱 전용 여부: 학생·선생님·수강·권한 / 반·교재·시간표 / 일정 / 일지 / 문자 템플릿 / 성적
   - 외부 정리 단계마다 진행 가능 여부와 직접 할 일
   - 최근 7일 사용량과 Notion을 부른 화면 목록
3. **일정 웹훅 보호 추가**: 일정 앱 전환 뒤 Make가 보낸 일정은 반영하지 않습니다(`APP_AUTHORITY`). 전에는 앱에서 만든 일정만 보호해서, Notion에서 온 일정을 Notion에서 고치면 앱 값을 덮어쓸 수 있었습니다. 일지 웹훅은 이전 구간부터 같은 보호를 하고 있습니다.

## 정리 순서 (사용자 진행, 각 단계 승인 후)
| 순서 | 조건(카드에서 "진행 가능") | 할 일 | 되돌리기 |
|---|---|---|---|
| 1 | 일지 앱 전용 | Make에서 **수업 일지 리포트** 시나리오 끄기 | 시나리오 다시 켜기(전환 중에는 반영이 어차피 차단됨) |
| 2 | 일정 앱 전용 | Make에서 **일정** 시나리오 끄기 | 같음 |
| 3 | 학생·선생님 앱 전용 | 선생님들께 Notion 성적 수정 중단을 알리고, 카드의 "최근 7일 Notion 성적 반영"이 0인지 확인한 뒤 Make **성적** 시나리오 끄기 | 시나리오 다시 켜기 |
| 4 | 문자 템플릿 앱 전용 | Cloud Run 템플릿 반영 작업기 중지, `MESSAGE_TEMPLATE_SYNC_ENABLED=false` | 작업기 재시작(전환 해제 후에만 의미 있음) |
| 5 | 모든 영역 앱 전용 + 앱 화면의 Notion 호출 0 | Notion 연동에서 쓰기 권한을 빼고 읽기만 남기기. 쓰지 않는 DB 공유 해제 검토 | 연동 권한 다시 부여 |

- 5번 뒤에도 **무결성 점검(관리자 진단)** 은 원본 대조를 위해 Notion을 읽습니다. 그래서 읽기 권한은 당분간 유지하길 권합니다.
- Notion 원본 DB와 페이지는 지우지 않습니다. 보관용 원본으로 남깁니다.
- 문제가 생기면 각 기능의 `전환 해제`로 이전 방식으로 돌아갈 수 있습니다. 앱 자료는 그대로 남습니다. 이미 끈 Make 시나리오는 다시 켜야 합니다.

## 검증
- lint 통과, 테스트 719/719, build 통과, Node 서버 import 통과.
- 새 `tests/notionDisconnect.test.ts` 4건:
  - DB 영역 분류(ID 저장 없음)
  - 실제 Notion 클라이언트 호출이 요청 경로와 함께 기록되는지
  - 영역별 전환·7일 집계·남은 화면에 따른 단계 판정. 관리자 진단만 남으면 권한 축소 가능, 상태 조회는 쓰기 0
  - 일정 전환 후 Make 일정 수신을 아무것도 쓰지 않고 거부
- 미리보기에서 카드를 확인했습니다(`design-proof-rosy-peach/8-notion-disconnect.jpg`).
- 사용량은 배포 이후부터 쌓입니다. 정리 판단은 배포 후 며칠 기록을 보고 하길 권합니다.

  - 범위: 선생님·관리자·원장 계정 × 6개 화면 구역(전체·일지·학생·일정·커리큘럼·설정) × 일반/빠른 요청, 강제 새로고침 포함

  - 코드 기준으로 앱 화면의 Notion 분리는 확인됐습니다. 남은 Notion 사용은 관리자 진단·설정·이전 도구뿐입니다.
- **연결 정리 카드에 전환 순서와 위치 표시**:
