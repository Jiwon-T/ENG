# 체크포인트 10 B hotfix 7 — 자습 상시 표시와 상단 정렬

- 단일·여러 학생 작성 모두 자습 회차/시작/종료/프리셋을 항상 표시한다. 접힘과 안내 문구를 제거했다.
- 수업·자습 카드는 같은 행 구조이며 grid-auto-rows:1fr로 같은 높이를 유지한다. 자습 ‘있음’ 선택 시 입력 가능, 미확인/없음에서는 기존 disabled/필수 조건을 유지한다.
- 팝업의 이 학생 선택 · 날짜+입력칸 · 과목+값을 한 줄에 배치한다. 날짜/과목 라벨은 입력 위가 아닌 왼쪽이다. 폭을 필요한 만큼만 사용하고 좁은 화면은 줄바꿈한다. 과목은 기존 읽기 전용 표시를 유지한다.
- 기존 저장/반영/회차 함수 20개와 API/캐시/자동 회차 등 94개 파일은 이전과 동일하다. changeSession의 값·콜백·필수·disabled 조건도 유지했다.
- 기존 접힘 테스트는 새 요청인 상시 표시를 확인하도록 바꿨다. npm run lint, npm test 523/523, npm run build 통과.
- 모의 브라우저 1440×900: 수업/자습 각각 높이 124.125px, 선택/날짜/과목 시작 y=201.6875px 및 높이 38px 동일. 자습 있음 전환 시 시작 입력 활성화와 기존 시간 초기화 동작 확인.
- 1440 및 390px 단일/팝업 스크린샷: docs/hotfix-7-proof. 이전 docs/density-proof는 hotfix 6의 기록이며 최신 화면은 hotfix-7-proof를 참고한다.
- 운영 데이터/배포/Notion 반영은 수행하지 않았다. 실제 모바일 기기·IME는 미확인이다.
