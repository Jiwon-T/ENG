# 재개 기록 — 성적 관리/이전 도구
기준: ENG-firestore-C1-app-registration.zip 전체 누적. 성적 일괄 입력/초성/저장 전 반영/삭제와 성적 데이터 Firestore 경로, 관리자 과거 자료 이전 도구 구현. lint/657개 테스트/build/Node import 통과. 실제 운영 이전/배포/브라우저 검증 미실행.

다음:
1. 사용자가 배포 후 한 학생/여러 학생 성적을 확인. 관리자 과거 성적 도구는 먼저 저장 없는 확인만 수행하고 오류/누락/작성자 연결을 대조. 실제 이전은 확인한10건씩 수행.
2. 최종 원본 편집 중단 이후 새 대조 순회와 삭제/관계 해제/중복/작성자 대조. done을 최종 검증 완료로 취급하지 않음.
3. C-1 학생·수강·담당 실제 이전/대조 상태 확인. 아직 core authority가 비활성이라면 공통 권한/명단에 남은 Notion 의존도 처리.
4. 중간에 추가된 성적 요청을 우선 처리했으므로, 원래 다음 대상으로 조사한 ‘일정’ Firestore 저장/공개/취소 전환을 다음 구현 구간에서 이어감. 그 뒤 일지 공개/원본 이전·남은 리포트 소비 경로 검증.

원본/앱 최신 수정 보호, 기존 계정·PIN·URL·내부ID 보존. 운영 자료 임의 삭제/병합 금지. 실제 SMS/Make 중단은 별도 승인 전 금지. 필요한 실제 운영 결과 없이 마이그레이션 완료나 모든 Notion 호출 제거로 보고하지 않음.
