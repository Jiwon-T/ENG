# 학생 카드와 상단 관리 탭 모달

체크포인트 9 및 핫픽스 1~9 전체를 포함합니다. 이번 요청의 1번만 구현했습니다. 이전에 예정한 본 체크포인트 10 작업은 이 학생 카드 구간과 별개로 남아 있습니다.

## 화면 동작

첨부 image(20261005-160704).png의 학생 카드 내 다섯 버튼을 확인했습니다. 카드 자체를 하나의 native button으로 바꾸고 기존 버튼들을 제거했습니다. 학생 이름·수강 상태·계정 연결·보호자 연락처 여부는 유지하며 한 행 4명 배치와 검색·상태/과목 필터·20명 단위 페이지네이션을 유지합니다. 흰 바탕, 핑크 hover/focus 표시를 제공합니다. 카드 버튼은 Enter/Space로 열 수 있습니다.

관리자·원장은 클릭하면 정보 수정이 먼저 열립니다. 모달 상단의 탭은 정보 수정 → 수강·담당·반 관리 → 리포트 확인 → 수업 작성 → 보호자 문자입니다. 일반 선생님은 기존 권한대로 리포트 확인 → 수업 작성 → 보호자 문자만 제공하고 리포트 확인을 먼저 엽니다. 정보 수정 및 수강 관리를 일반 선생님에게 새로 허용하지 않았으며 서버 권한 검증도 그대로 유지합니다.

동시에 열리는 학생 관리 native dialog는 한 개입니다. 기존 정보/수강/문자/리포트 화면의 내부 WorkspaceDialog는 학생 관리 모달 안의 본문으로 재사용합니다. 필요한 기능을 열 때만 기존 lazy 컴포넌트를 로드합니다. 충돌 검토 등 내부 별도 확인창은 자신의 원래 모달 동작을 유지합니다.

상단 탭은 tablist/tab/tabpanel로 표시하고 좌우 방향키·Home/End 이동을 제공합니다. 작은 화면에서는 탭이 줄바꿈됩니다. 전환은 기존 편집 화면의 close 확인을 거칩니다. 저장하지 않은 정보·수강 변경과 문자본문·직접 작성한 수업 내용은 확인 후 전환할 수 있습니다. 취소한 전환은 대기열에 남기지 않고 다음 닫기에 잘못 실행되지 않습니다. 수업 작성은 선생님방 다른 메뉴로 이동하지 않고 같은 학생 관리 모달에서 전체 일지 폼을 엽니다. 학생 선택은 해당 학생으로 고정하고 선생님 담당 과목을 우선 선택합니다. 직전 일지 불러오기·초안 저장·노션/리포트 반영·실패 재시도는 기존 코드를 재사용합니다.

정보·수강 저장 성공 시 기존처럼 관리 모달을 닫고 학생 목록을 갱신합니다. 탭 전환에서 현재 편집 화면은 해제되므로 확인 후 버린 입력은 복원하지 않습니다. 반영 결과가 불명인 정보·수강 요청은 서버에 보관한 기존 요청으로 다시 열어 확인합니다. 문자 발송은 기존대로 본문 저장과 수신자·본문 최종 확인 이후에만 수행합니다. 단순 카드 클릭이나 탭 이동으로 발송하지 않습니다.

## 검증

전체 테스트 421개 통과. 최종 변경 후 새 학생 관리 테스트 5개도 재확인했습니다. TypeScript 검사, Vite 빌드, native 서버 import 검사 통과. 기존 큰 chunk 및 firebase 혼합 import 빌드 경고는 유지됩니다.

새 검증은 카드 내 단일 버튼, 관리자 초기 정보 수정과 5개 탭/단일 native dialog, 일반 선생님의 3개 허용 기능과 리포트 기본 화면, 취소·busy 전환의 상태 보존, 오래된 패널 cleanup과 잘못된 전환 대기 방지를 포함합니다. 화면 검증은 컴포넌트 HTML 렌더 및 탐색 로직 테스트이며 실제 배포 화면에서의 클릭 검증은 수행하지 않았습니다. 서버 저장·반영·권한 관련 기존 테스트도 통과했습니다.

이번 구간은 앱 코드만 수정했습니다. 실제 노션·운영 데이터·배포·문자 발송·Make 변경은 하지 않았습니다.

다음 구간은 단어 세트의 시험기간 대비 단어장 카드와 개별 단어장 디자인, 지난 시험 기간 카드 정리입니다. 이후 본 체크포인트 10을 재개합니다.
