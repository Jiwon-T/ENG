# 체크포인트 10 B hotfix 11

## 변경
- 과거 일지 자동 입력에 출석·태도·숙제·테스트와 일반/내신 점수(정답·문항·오답)를 추가했다. 단일 작성과 여러 학생 작성이 같은 함수를 쓴다.
- 앱 previous-lesson 응답은 기존 필드를 보존하면서 평가·점수를 추가한다. Notion fallback은 출석 select, 평가 status/select와 실제 단어/틀린 단어/문항 수/오답 수 숫자 속성을 읽는다. 환산 수식으로 원점수를 추정하지 않으며 0과 빈 값을 구분한다.
- 오늘 수업 완료 표시가 사용하는 학생·날짜·과목·시작 시간 기준으로 저장 기록을 열도록 통일했다. 저장된 종료 시간이 일정과 달라도 해당 기록의 ID·revision·전체 내용·평가·점수·회차를 그대로 연다. 일반 학생 추가의 정확한 시작/종료 일치 기준은 유지한다.
- 오늘 그룹 재클릭 때 같은 행이 중복 추가되지 않도록 동일한 매칭 기준을 적용했다.
- 직접 수정한 평가를 늦은 조회 응답으로 덮어쓰지 않는다. 점수는 정답·문항·오답 한 묶음으로 보호해 일부 수치만 과거 값으로 바뀌지 않게 한다.

## 유지 및 검증
- 월별 자동 회차, 저장/반영 요청과 권한 검사, 캐시 정책과 브라우저 저장소 제한은 유지했다. 운영 데이터, 배포, 실제 SMS, Make는 변경하지 않았다.
- 기존 자동 입력 테스트의 '평가를 초기화한다' 기대값은 이번 사용자 요청에 따라 '과거 평가·점수를 복원한다'로 변경했다. 이는 요청한 동작 변경이다.
- 타입 검사, 전체 테스트 535개, 프로덕션 빌드. 새 검증은 앱/Notion 응답의 평가와 실제 0점, 수동 수정 보호, 종료 시간 불일치 시 저장 기록 복원을 포함한다.
- 운영 화면 확인은 수행하지 않았다. 배포 후 오늘 반영 완료 항목 클릭 → 평가·점수·회차·저장 상태 확인, 다른 날짜의 새 일지 학생 선택 → 과거 평가·점수 자동 입력, 조회 중 직접 변경 → 값 유지 순서로 확인한다.
- 기존 메모리에 없는 완료 일지 전체를 조회하는 기능은 추가하지 않았다. 이 전달본은 이전 변경을 모두 포함한다.
