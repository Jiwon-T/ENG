# 학교별 시험기간 자료 관리

선생님방 > 학습 세트 > 시험기간과 학생 메인화면 > 시험기간은 동일한 시험기간 분류를 사용합니다.

- 학교, 학년, 연도, 학기, 중간/기말, 준비 시작일/종료일을 설정합니다.
- 준비 중은 학생 목록에 표시하지 않습니다. 공개 중 자료는 학생이 학습할 수 있습니다.
- 종료일 다음 날(한국 시간) 또는 종료 상태로 바꾸면 지난 시험기간에 접혀 보관합니다.
- 종료 후 계속 공개는 기본으로 켜져 있으며 끄면 학생 목록에서 숨깁니다. 자료 자체는 유지됩니다.
- 시험기간 삭제 기능은 제공하지 않으며 Firestore 규칙에서도 삭제를 차단합니다.
- 기존 단어장·문법 자료를 여러 시험기간에 연결할 수 있습니다. 새 기간으로 복사는 자료 연결을 재사용하며 원본을 복제하지 않습니다. 공유 원본을 수정하면 모든 연결 기간에 반영되므로 당시 내용을 독립적으로 보존하려면 별도 단어장을 만들어 연결하세요.
- 시험기간에 연결된 단어장의 삭제 버튼은 먼저 연결 해제를 요구합니다. 이 검사는 앱 UI에서 수행하며 직접 DB 관리자 작업까지 막지는 않습니다.
- 기존 시험기간 단어장은 미지정 자료에 유지됩니다. 기간 관리에서 연결할 수 있습니다.
- 학생 users 문서의 school 또는 schoolName, grade가 분류와 일치하면 해당 학교·학년을 기본 선택합니다. 등록 정보가 없으면 필터에서 직접 선택합니다.

## 배포

앱 코드와 함께 firestore.rules를 배포해야 examMaterialPeriods 컬렉션의 읽기·저장 권한이 적용됩니다. 별도의 데이터 이관이나 복합 인덱스는 필요하지 않습니다. 기존 자료는 변경하지 않습니다.

검증: TypeScript 검사, 209개 테스트, 프로덕션 빌드 통과. 실제 로그인 화면과 운영 Firestore에서의 클릭 검증은 별도입니다.
