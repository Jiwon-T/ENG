앞서 보고하고 사용자에게 승인받은 모의 측정: 비어 있는 자료 기준 첫 report-review HTTP 1회→1회, Firestore 서버 연산 cold 학부모/일정 3→학생/온라인 8. 기존 일정 warm 캐시 경우 0→8. 온라인 첫 페이지 한도는 세션 20개/과제 10개로 유지됩니다. 이전 측정의 비어 있는 응답은 217→288바이트입니다. Enterprise 실제 읽기 단위나 실제 학생 응답 바이트는 아닙니다.
재원생 이동·유형 칩·요약·추이에 서버 동기화 요청을 추가하지 않았습니다. 콤보박스와 필터는 이미 로드한 자료만 사용합니다. 요청 수 실제 브라우저 계측은 미확인입니다.
